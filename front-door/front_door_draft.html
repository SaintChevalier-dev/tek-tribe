Four doors (in order)

1. Invite-only login (/login). Supabase invite only. The player enters the invite code or clicks the invite link. No open signup.
2. Membership check (/gate). Confirms the logged-in player is a member. Membership is game access, with no bypass.
3. Spawn (/spawn). Places the player at their start point (default: start). No spawn without membership.
4. First view (/world). Party, active quest and one next move.
